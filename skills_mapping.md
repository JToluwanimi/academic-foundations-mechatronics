# Skills Taxonomy — Evidence-Based

Every skill listed is backed by documented evidence. No skill is claimed without a traceable source.

## Proficiency Levels

| Level | Definition |
|-------|------------|
| **Applied** | Used on a completed project with documented evidence |
| **Developing** | Used in learning projects or in progress |
| **Foundational** | Coursework or theoretical exposure |
| **Studied** | Analyzed but not implemented |
